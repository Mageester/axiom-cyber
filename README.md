# Axiom Cyber

Marketing site for Axiom Cyber — security assessments, penetration testing, and infrastructure hardening.

## Stack

- React 19 + Vite 8
- React Router 7
- Tailwind CSS 4

## Scripts

```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run preview  # preview production build
npm run lint
```

## Deploy

Build output is static (`dist/`). Point your host (Cloudflare Pages, Netlify, etc.) at that directory.
